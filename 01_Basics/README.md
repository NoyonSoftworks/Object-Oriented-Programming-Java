# 🧠 Java Basics / Fundamentals

This folder contains beginner-friendly Java programs that teach the **core fundamentals** you should know **before OOP**.  
All files are short, clean, and easy to run.

---

## 📂 What’s inside

| File | What you learn |
|---|---|
| `HelloWorld.java` | Your first Java program, `System.out.println` |
| `CommentsExample.java` | Single-line, multi-line, and Javadoc comments |
| `VariablesAndDataTypes.java` | int, double, char, boolean, String |
| `OperatorsExample.java` | Arithmetic, relational, logical operators |
| `InputExample.java` | Taking user input with `Scanner` |
| `ConditionalStatements.java` | `if / else if / else`, `switch` |
| `LoopsExample.java` | `for`, `while`, `do-while` loops |
| `BreakContinueExample.java` | `break` and `continue` in loops |
| `ArrayExample.java` | 1D arrays, indexing, iteration |
| `StringExample.java` | Common String methods (`length`, `toUpperCase`, `charAt`, …) |
| `MethodExample.java` | Writing and calling your own methods |
| `MathExample.java` | `Math.sqrt`, `pow`, `abs`, `max`, `min`, `random` |
| `NestedLoopExample.java` | Nested loops + simple star pattern |

---

## ▶️ How to run (terminal)

1. Open this folder in a terminal.
2. Compile:
   ```bash
   javac FileName.java
3. Run:
      java FileName

Tip: In VS Code you can also use the Code Runner extension (▶️ button).
