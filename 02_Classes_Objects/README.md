# 🚗 Java Classes and Objects

This folder contains examples that explain how **classes and objects** work in Java — the foundation of **Object-Oriented Programming (OOP)**.

All examples are short, beginner-friendly, and clearly show how Java handles real-world entities using **attributes** and **methods**.

---

## 📘 Topics Covered

| File | Description |
|------|--------------|
| `Car.java` | Basic example of a class and object — defines properties and methods. |
| `ConstructorExample.java` | Demonstrates default and parameterized constructors. |
| `ThisKeywordExample.java` | Shows how to use the `this` keyword to reference instance variables. |
| `StaticExample.java` | Explains `static` variables, methods, and how they belong to the class. |
| `ObjectArrayExample.java` | Creates and manages an array of objects. |
| `AccessModifierExample.java` | Demonstrates public, private, and protected access levels. |

---

## 🧩 Concepts You’ll Learn

✅ What are **classes and objects**  
✅ How to define **fields (variables)** and **methods (functions)**  
✅ How to use **constructors** to initialize objects  
✅ What the **`this` keyword** means  
✅ How **static members** work  
✅ Access control using **modifiers**  
✅ Working with **multiple objects**
