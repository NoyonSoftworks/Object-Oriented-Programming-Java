# 🧬 Java Inheritance

This folder contains examples that explain **Inheritance in Java**, a key concept of Object-Oriented Programming (OOP).  
Inheritance allows one class to **reuse and extend** the properties and methods of another class — helping reduce code duplication and improve reusability.

---

## 📘 Topics Covered

| File | Description |
|------|--------------|
| `PersonTeacherExample.java` | Demonstrates basic single inheritance (Person → Teacher). |
| `MultilevelInheritance.java` | Shows multilevel inheritance (Person → Teacher → HeadTeacher). |
| `HierarchicalInheritance.java` | Demonstrates hierarchical inheritance (one parent → multiple child classes). |
| `SuperKeywordExample.java` | Uses the `super` keyword to call parent variables, methods, and constructors. |
| `FinalKeywordExample.java` | Explains `final` variable, method, and class — prevents modification or inheritance. |

---

## 🧩 Concepts You’ll Learn

✅ What is **inheritance** and why it’s used  
✅ How to **reuse parent class code** using `extends`  
✅ How constructors work in inheritance (constructor chaining)  
✅ Difference between **single**, **multilevel**, and **hierarchical** inheritance  
✅ Use of **`super`** and **`final`** keywords  
✅ How overriding works between parent and child classes
